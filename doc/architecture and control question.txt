Kuavo Bipedal Robot Controller - Architecture and Control Questions
====================================================================

DECISIONS MADE
==============

Control Loop Architecture
-------------------------
- Control frequency: Reduced from 1000Hz to 200Hz (to match state estimation rate)
- State estimation rate: 100Hz (DynaControl)
- Thread priorities: Leg controller threads > IMU thread
- Scheduling policy: SCHED_FIFO
- Priority inheritance: Implemented
- Shared memory: Agreed as better approach than message queues, but not yet implemented

CAN Bus Failure Handling
-----------------------
- Architecture: Two CAN buses (one per leg)
- Failure detection: Single CAN bus failure triggers immediate emergency stop
- Detection logic: 2 consecutive missed messages
- Emergency stop mechanism: GPIO pin to hardware emergency stop system
- Transition: No intermediate "degraded operation" state
- Visual/audio indication: LED on robot + sound buzzer

IMU Failure Handling
--------------------
- Detection: 2 consecutive missed messages in a row
- Response: Immediate emergency stop

Motor Overheating
-----------------
- Response: Graceful shutdown (not emergency stop)
- Implementation: To be defined

Computer/System Failure
-----------------------
- Response: Emergency stop

CONTROL THEORY CONSIDATIONS
===========================

Rate Mismatch Analysis
-----------------------
- Current: 100Hz state estimation, 200Hz control loop
- Issue: 2x rate mismatch requires prediction/extrapolation
- Risk: State estimation errors compound in high-speed control
- Alternative: Match rates (200Hz both) or accept lower control frequency

Bipedal Dynamics
----------------
- Fast dynamics require fresh state estimates
- Foot slip can occur in milliseconds
- Extrapolation for multiple control cycles is risky
- Balance control requires precise timing

Real-Time Constraints
---------------------
- 200Hz = 5ms period
- Context switch overhead must be measured
- Priority inversion risks addressed with inheritance
- Thread priorities defined but need validation
